# 4. YÊU CẦU CHỨC NĂNG

## 4.1 Nhóm chức năng Khách vãng lai
1. Xem danh sách chuyên khoa.
2. Xem danh sách bác sĩ.
3. Xem chi tiết bác sĩ.
4. Xem lịch trống theo ngày.
5. Đăng ký tài khoản.
6. Đăng nhập.

## 4.2 Nhóm chức năng Bệnh nhân
1. Xem danh sách lịch hẹn.
2. Đặt lịch khám.
3. Hủy lịch khám.
4. Xem thông báo.
5. Cập nhật profile.

## 4.3 Nhóm chức năng Bác sĩ
1. Tạo/xem/sửa/xóa slot lịch làm việc.
2. Xem danh sách lịch hẹn theo ngày/trạng thái.
3. Xem chi tiết lịch hẹn (thông tin bệnh nhân + note).
4. Cập nhật trạng thái lịch hẹn.
5. Tạo/cập nhật hồ sơ bệnh án.
6. Tạo/cập nhật đơn thuốc.

## 4.4 Nhóm chức năng Admin
1. Quản lý users (khóa/mở khóa).
2. CRUD specialties.
3. CRUD services.
4. Setup doctor (gán specialty + service).
5. Quản lý appointments.
6. Xem báo cáo tổng quan.

## 4.5 Chức năng hệ thống
1. Check trùng lịch khi đặt khám.
2. Nhắc lịch tự động (cron reminders).
3. Audit log cho các thao tác auth/quản trị.
