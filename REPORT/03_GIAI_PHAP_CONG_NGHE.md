# 2. GIẢI PHÁP CÔNG NGHỆ

## 2.1 Công nghệ sử dụng
- **Next.js**: xây dựng API và frontend trong cùng dự án.
- **TypeScript**: tăng độ an toàn kiểu dữ liệu.
- **MySQL**: lưu trữ dữ liệu nghiệp vụ.
- **bcrypt + JWT**: bảo mật mật khẩu và xác thực token.

## 2.2 Lý do lựa chọn
- Next.js phù hợp dự án fullstack nhỏ-đến-vừa.
- MySQL dễ quản lý quan hệ users-doctors-appointments.
- JWT phù hợp API stateless.

## 2.3 Công cụ phát triển
- Visual Studio Code
- Postman
- XAMPP/MySQL local
- Git (quản lý phiên bản)
